## Changes

- **Step-by-step agent workflows** — give your coding agent one instruction at a time while Stepan keeps the graph and decides the next step from the reported outcome.
- **Editable flows** — define steps in YAML and instructions in Markdown, with string or enum outcomes, conditional transitions and returns for rework.
- **Install from Git** — copy flows from a Git repository into your project and run them locally without further network access.
- **Independent runs** — start separate runs, resume the current step and retain each run's transition history.
- **Flow-authoring skill** — install an optional Agent Skill to help create and edit flows with a complete offline format reference.
